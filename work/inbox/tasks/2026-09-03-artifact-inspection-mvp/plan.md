# 实施顺序

总体方案只维护在 [开发计划](../../../product/artifact-inspection/implementation-plan.md)，此处定义任务推进顺序，不复制完整设计。

1. P0：授权启动后，盘点实际样例和工具/Skill；验证一个 Viewer 与一个官方 Skill 的真实输入/输出和资源闭包；完成兼容矩阵与必要 seam 决策。
2. P1：按已验证契约实现 Record/Profile、动作就绪度和通用打开，兼容旧记录；不改变数据原文。
3. P2：依赖图→草稿→Session→官方分析→报告，验证版本绑定、first-send 和失败恢复。
4. P3：扩展泳道、关键路径、内存、IR/计算图与受支持 legacy；逐适配器验收。
5. P4：图状态恢复、选区和结果定位等增强；不支持的 viewer 明确降级。
6. 完成：记录已支持范围、真实验证证据和未完成项，回写主题，归档任务；不自动发布。

每阶段先核对授权和前一阶段证据。若 P0 发现工具不可用，先给最小阻塞/可替代方案，不跳过验证后宣称进入下一阶段。
