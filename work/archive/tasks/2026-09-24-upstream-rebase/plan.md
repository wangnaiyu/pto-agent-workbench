# 执行计划

1. P0 固定基线：核实两仓工作树、远端与 upstream 目标；记录差异范围、版本与兼容风险，建立旧 master 保存点。完成标准：SHA、授权、回退路线清楚。
2. P1 重放与适配：隔离候选 checkout rebase；逐项解决冲突、审计 range-diff 与持久化类型。完成标准：fork 提交对应明确，必要修复就位。
3. P2 兼容验证：锁定安装、完整构建、受影响 PTO/GUI/session tests、离线回放、浏览器与真实外层 patch 隔离 smoke、类型/文档/包门禁。按实际变更选择命令，失败归因并修复。完成标准：证据完整，未验证边界清楚。
4. P3 安全更新：正常提交，重新核验远端与精确 OID；推送备份和候选，再精确 lease 更新 fork master，核验远端与本地同步。完成标准：master 等于验证提交，恢复点存在。
5. P4 配对与归档：回写长期文档，归档任务；外层提交与 harness 创建同名 annotated 配对 tag、记录两仓 SHA 与 upstream，推送并核验。完成标准：两仓新基线可恢复，状态与报告无遗漏。
