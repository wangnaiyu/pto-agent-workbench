# 实施计划

1. R0 固定基线与目标：核对两仓工作树、远端、恢复点及 upstream 变化；记录完整 SHA 与影响面。
2. R1 隔离重放：保存旧 master，在独立 worktree 重放 fork 非 merge 提交；审计 range-diff、合并特有变更与冲突，不丢 PTO 行为。
3. R2 兼容验证：按新版指令适配所有受影响消费者；执行聚焦测试、完整构建、契约与装配门禁，分类失败；隔离工作台验证关键首发、Viewer、Skill 与布局。
4. R3 安全更新 master：验证完成后保存候选，重新核验远端未移动，使用目标 ref 和观察 OID 的精确 lease；核验远端结果及 CI。
5. R4 新配对与收尾：保存两仓及固定 upstream 完整 SHA、检查证据、已知限制和恢复方式，更新正式维护文档并归档，提交及保存配对 tag。

每项执行前/后更新 status checkpoint。失败未解决不得将候选标为已验收或更新 master。
