# 恢复此任务

从 pto-agent-workbench 外层仓库进入。先读根 AGENTS 和项目工作流 Skill，再读本包 README、status、plan。检查外层与 harness 的实际 HEAD、工作树和适用规则，区分设计确认与执行授权。

本文件不授予执行权限；planned 状态尚未获启动授权时，说明具体下一步并等待用户决定。获授权后只推进当前阶段，读取对应主题和必要上游 Skill/资源，记录真实验证，不从归档的旧“下一步”重启已完成工作。

执行时遵循 [任务流程](../../../../docs/task-workflow.md) 中的逐子任务开始/完成 checkpoint 协议；每项验收、状态落盘和必要正式文档回写完成后，才进入下一项。中断恢复先核对已记录的执行标识、真实产物与验证状态，不重复启动结果未知的操作，也不从头重做已验收部分。

重要决定改变或出现阻塞时及时更新 status。大原始数据不复制进仓库，可重建中间产物放本包 scratch，唯一证据不能只在那里。源码/设备执行、fetch、提交和发布各自按授权处理。
