# update-2026-08-21

## review / decision / clarification 分区元数据格式统一

### 变更

- 恢复 Claude 原先在 `## <workflow-or-topic>` 下使用的“本分区”引用式元数据行，格式见 `notes/README.md` 第 7 条。
- `notes/README.md` 将 review / decision / clarification 的统一格式从 Markdown 表格改为引用式元数据行，并固定引导语、字段顺序与标点。
- `notes/decision-2026-08-20.md` 的 3 个 workflow 分区已全部迁移到该格式。

### 理由

- 引用式元数据比 YAML 定界块和表格更紧凑，在 Markdown 源文与 preview 中都容易扫读。
- 该格式是项目内的 Markdown 约定，不声称为可被工具解析的 YAML frontmatter。

### 验证结果

- 结构校验：decision 文件顶层无 YAML frontmatter，每个 `##` workflow 分区后均紧跟一行格式一致的引用式元数据。
