## 3180 会话隔离（DSH_HOME 独立）

### 变更

- `start.sh`：工作台固定使用独立 DSH_HOME（`~/.dsh-pto-workbench`），并清理调用方（官方 3080 实例 agent bash）注入的 `DSH_SHELL` / `DSH_SESSION_ID` / `DSH_SESSION_JSONL` / `DSH_WEB_URL`。
- 新 home 预置：复制 `.credentials.yaml`、`.anonymous-user-id`、`settings.yaml`（首次需手动准备，含 API key）。

### 事实依据

- 用户要求（2026-08-20）：3080 与 3180 会话记录隔离。
- 机制核实（harness 源码 `packages/util/home-paths`）：DSH 数据按 DSH_HOME 分区（显式配置 > `$DSH_HOME` > `~/.dsh`），会话持久化于 `$DSH_HOME/sessions/`；端口不参与数据分区。

### 影响范围

- `start.sh`、`~/.dsh-pto-workbench`（新建，仅本机）。

### 验证结果

- 3180 进程 env：`DSH_HOME=~/.dsh-pto-workbench`（会话注入变量已清空）。
- 3180 打开文件全部位于 `~/.dsh-pto-workbench/`（含 profiles/web/cordis.yml）。
- 新旧 home 会话数：新 0 个（全新）、旧 2 个（3080 记录保留）。

### 验证结果

- macOS arm64 发行 tarball 大小 64.8 MB，嵌入运行时 65.1 MB。
- 在空的临时当前目录和独立 home 中执行本地等价 `npm exec --offline --package=<tarball>`，能启动临时端口并返回 `<title>PTO Agent 工作台</title>`。
- 薄 launcher 依赖官方 DSH 的初版方案在空 npm cache 中超过 300 秒仍停留于 metadata 解析，已否决。
