# update-2026-08-25

## 新会话输入框 `+` 的草稿能力目录：动态 spike

### 变更

- 新增 `experiments/draft-composer-catalog-spike/`：`host.js` 是可交给 `cordis_define` 的纯 JavaScript Host half；`run-spike.ts` 通过真实 `DynamicCordisRunnerService.define()`、`run()` 与 `invoke()` 执行完整回路。
- `harness/packages/interaction/commands` 新增 `listGlobalDescriptors()` 与 `listForScope(scope)` 两个只读查询，允许 Host 在不构造 Agent 的情况下读取全局与 standing-scope 有效命令描述符。
- `harness/packages/preset/agent-presets` 新增 `serviceForStanding(standingKey, name)`，允许 Host 在无 Agent 状态下解析 preset isolate realm 内的服务；服务缺失时不回退 Host 根服务。
- 同步更新命令与 preset 包 README、既有 Agent Notes，以及生成的 Cordis Host inspect / subsystem catalog。

### R1 理由

纯动态插件原本无法可靠读取命令注册表的全局层或 standing-scope 视图，也无法在无 Agent 状态下寻址 preset isolate realm 内的 Skills 服务。两个扩展都只增加只读查询，不提供草稿执行、不创建 Agent/Session、不改变首次发送生命周期；来源过滤、冲突裁决、协议、缓存与 UI 仍留在后续静态边缘 package。

### 验证结果

- 命令注册表与 preset mount 定向测试：2 个文件、103 个用例通过。
- 动态 spike：未分组仅返回两个全局命令，preset 与 Skill registry 调用数均为 0；Workspace 返回两个全局命令、含 Agent 新增/覆盖的三个有效命令，以及唯一的 `project-agents` Skill。
- 两种查询前后 live Session id 列表均为空；持久化快照保持 `existing-session@rev-7`，`lifecycleUnchanged` 均为 true。
- preset 隔离测试证明 `serviceForStanding()` 能取到 Host 根不可见的 realm-private 服务，且不会以同名 Host 根服务替代缺失项。
